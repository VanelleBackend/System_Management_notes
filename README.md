# Projet : Système de gestion des notes

## ⏳ Objectif global: 

Nous devons mettre sur pied chacun un système de gestion de notes intégrant au moins 3 fonctionnalités fares, chacun travail dans un branche portant son nom.

## ✅ Flux de travail recommandé

### 🧪 Création et gestion de branche Git

Chaque travail doit suivre ce protocole :

1. Créer une nouvelle branche dédiée à ton travail :

   ```bash
   git checkout -b Ton_nom(ceci sera le nom de ta branche git)
   ```

2. Créer un dossier dans :

   ```
    System_Management_Notes/
   ```

3. Travailler à l'intérieur :

   * Scripts(python, php, js, etc...)
   * README.md
   * Ressources (JSON, .txt, etc)

4. Ajouter, committer et push :

   ```bash
   git add .
   git commit -m "Initialisation du projet Nom_du_projet"
   git push origin Nom_branche_git
   ```

## 🗂️ À faire dans chaque projet

Chacun dans le dossier qui est dans sa branche, ajoute un fichier `README.md` avec les sections suivantes :

### 🔹 Objectif du projet

Explique ce que fait ton projet, en quelques phrases.

### 🔹 Technologies utilisées

Indique les bibliothèques ou outils que tu as utilisés.

### 🔹 Instructions d'exécution

Indique la commande pour exécuter ton script, par exemple :

```bash
php index.php
```

Et les prérequis s’il y en a (`composer install`, etc.).

### 🔹 Utilisation

 Démarche pour executer son travail
